# OpenShortcuts landing page

SvelteKit + Svelte 5, built as a static site and published to GitHub Pages by `.github/workflows/pages.yml`.

```bash
npm install
npm run dev
```

Colors and shapes in `src/lib/tokens.css` match `app/src/main/java/app/openshortcuts/ui/Theme.kt`. Icons in `src/lib/glyphs.json` are exported from the app's `Glyphs.kt`.
